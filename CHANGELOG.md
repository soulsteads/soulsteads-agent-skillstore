# Changelog

## 0.1.1 (proposed)

No previous GitHub tag. These notes cover the full public source history.

### Highlights

- First tagged-source candidate for Skillstore: manage reviewed skills with local catalog, installation and rollback commands.
- Include reviewed MCP contributions, remote HTTPS registries, local and hosted Git sources, and private Hermes skill backup and recovery.
- Add approval-free local skill snapshots and verified recovery into a new directory. Expose the reviewed catalog over bearer-authenticated Streamable HTTP MCP; install, contribute and back up locally.
- Include the Apache-2.0 license and updated setup, support and usage guidance.
- Standardize `LICENSE` and `NOTICE` with author Scott Glover and `Copyright (c) 2026 Soulsteads`. The Apache-2.0 terms are unchanged.
